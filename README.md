# Y2K ARCHIVE — Hip-Hop Fashion Store

Учебный frontend-проект: адаптивный интернет-магазин и мини-цифровой архив, посвящённый эстетике хип-хоп моды 2000-х годов.

## О проекте

Y2K ARCHIVE объединяет визуальный стиль streetwear-культуры нулевых и базовые функции интернет-магазина. В каталоге представлены демонстрационные карточки товаров брендов Southpole, Coogi, ECKŌ Unltd., Ed Hardy, Affliction, Rocawear, New Era и Pelle Pelle.

**Важно:** это учебный концепт. Товары, графические изображения и цены демонстрационные; реальная оплата, доставка и подключение к складской базе не реализованы. Названия брендов используются для описания стилистической тематики проекта.

## Функциональность

- адаптивная вёрстка для компьютеров, планшетов и смартфонов;
- каталог товаров с карточками;
- фильтрация по категориям: верх, низ, аксессуары;
- поиск по бренду и названию;
- сортировка по цене;
- добавление и удаление товаров из корзины;
- автоматический подсчёт количества и общей суммы;
- сохранение корзины в `localStorage`;
- мобильное навигационное меню;
- демонстрационный сценарий оформления заказа без реальной оплаты.

## Технологии

- **HTML5** — структура и семантика страниц;
- **CSS3** — сетки, адаптивность, анимации и оформление;
- **JavaScript (Vanilla JS)** — каталог, фильтры, поиск, сортировка и корзина;
- **localStorage** — сохранение корзины в браузере;
- **Google Fonts** — типографика (при наличии подключения к интернету).

Сборщик и серверная часть не требуются.

## Запуск локально

1. Скачайте или клонируйте репозиторий.
2. Откройте папку проекта.
3. Откройте `index.html` в браузере.

Для удобной разработки можно открыть папку в Visual Studio Code и запустить `index.html` через расширение Live Server. Это необязательно.

## Публикация на GitHub Pages

1. Создайте новый репозиторий на GitHub, например `00s-hiphop-store`.
2. Загрузите в корень репозитория файлы `index.html`, `styles.css`, `app.js` и `README.md`.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`, затем нажмите **Save**.
6. После завершения публикации GitHub Pages покажет ссылку на сайт в разделе Pages.

## Как устроен код

### `index.html`
Содержит шапку, главный баннер, каталог, блок брендов, историю стиля и боковую панель корзины. В конце страницы подключён JavaScript-файл:

```html
<script src="app.js"></script>
```

### `styles.css`
Здесь находятся цвета проекта, шрифты, размеры, сетки, состояния кнопок и адаптивные правила `@media`. На широком экране товары располагаются в четыре колонки, на небольшом экране — в две.

### `app.js`
В начале объявлен массив `products` — источник данных каталога. Каждая запись содержит идентификатор, бренд, название, цену, категорию и CSS-класс оформления.

- `renderProducts()` выводит карточки и применяет фильтры, поиск и сортировку.
- `addToCart(id)` добавляет товар в корзину или увеличивает его количество.
- `renderCart()` обновляет содержимое корзины, счётчик и итоговую сумму.
- `saveCart()` сохраняет состояние корзины в `localStorage`.
- `openCart()` и `closeCart()` управляют боковой панелью.
